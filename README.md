## 🎥 ショート動画の挿入方法

以下のいずれかで簡単に動画を反映できます：

### 方法A: 動画ファイル（.mp4）を置く場合
1. 撮影した動画を `public/videos/intro.mp4` に保存
2. `src/data/portfolioData.ts` の `video.videoUrl` を編集:
   ```typescript
   video: {
     videoUrl: "/videos/intro.mp4",
   }
   ```

### 方法B: YouTube（限定公開）URLを使う場合
1. YouTubeに「限定公開」でアップロード
2. `src/data/portfolioData.ts` の `video.videoUrl` にURLを記述:
   ```typescript
   video: {
     videoUrl: "https://www.youtube.com/watch?v=YOUR_VIDEO_ID",
   }
   ```
